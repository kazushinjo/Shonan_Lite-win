# Shonan_Lite for Windows インストールマニュアル / Installation Manual

対象: Windows 10/11 (x64)  
Target: Windows 10/11 (x64)

対象読者: `ShonanLiteSetup.exe`（公式配布インストーラ）を使ってセットアップするユーザー  
Audience: users who set up with `ShonanLiteSetup.exe` (the official distributed installer)

本書は配布インストーラ`ShonanLiteSetup.exe`が導入する項目と、その手順をすべて記載した
インストール専用マニュアルです。アプリの操作方法は別紙の「操作説明書」
（`app/docs/build_operation_manual_win.py`で生成、ヘルプ画面と同内容。日本語版・英語版あり）を参照してください。

This is an installation-only manual that describes everything the distributed installer
`ShonanLiteSetup.exe` installs, and the procedure. For how to operate the app, see the separate
"Operation Manual" (generated by `app/docs/build_operation_manual_win.py`; same content as the Help
screen; available in Japanese and English).

## 1. 概要 / Overview

`ShonanLiteSetup.exe`は、Shonan_Liteの動作に必要な以下4つをすべてまとめた
オールインワン・インストーラです。個別に用意する必要はありません。

`ShonanLiteSetup.exe` is an all-in-one installer that bundles the following four components
Shonan_Lite needs. You do not need to prepare them individually.

| コンポーネント / Component | 役割 / Role | 導入方法 / How it is installed |
| --- | --- | --- |
| Shonan_Lite本体（GUI） / Shonan_Lite app (GUI) | DVB-S2 DATV送受信タッチGUI（PyInstallerで.exe化済み）<br>DVB-S2 DATV transmit/receive touch GUI (frozen to .exe with PyInstaller) | インストーラが展開<br>Extracted by the installer |
| ffmpeg | 映像/音声の入出力（USBカメラ・キャプチャ、送信映像のエンコード）<br>Video/audio input and output (USB camera/capture, encoding of the transmitted video) | インストーラがアプリフォルダ内に同梱<br>Bundled by the installer inside the app folder |
| radioconda | GNU Radio + gr-iio 実行環境（受信復調の土台）<br>GNU Radio + gr-iio runtime (the basis of reception demodulation) | インストーラがサイレントインストール<br>Silently installed by the installer |
| gr-dvbs2rx（事前ビルド済み / prebuilt） | DVB-S2復調のGNU Radioブロック本体<br>The GNU Radio block that performs DVB-S2 demodulation | インストーラがradioconda環境内へコピー<br>Copied into the radioconda environment by the installer |

これらを個別に手動導入する必要はなく、`ShonanLiteSetup.exe`を実行するだけで完了します。
（開発・改造目的でソースから直接実行する場合の個別セットアップ手順は
[README.md「インストール」方法2/方法3](../README.md#インストール--installation)、
gr-dvbs2rxを自分でビルドする手順は
[`docs/gr-dvbs2rx-windows/README.md`](gr-dvbs2rx-windows/README.md)を参照してください。
通常の利用ではどちらも不要です。）

You do not need to install any of them manually; just run `ShonanLiteSetup.exe`.
(For the individual setup steps when running from source for development or modification, see
[README.md "Installation", Method 2/Method 3](../README.md#インストール--installation); for building gr-dvbs2rx
yourself, see [`docs/gr-dvbs2rx-windows/README.md`](gr-dvbs2rx-windows/README.md). Neither is needed for
normal use.)

## 2. 動作環境 / System requirements

- OS: Windows 10 または Windows 11（**x64のみ**。32bit環境は非対応）  
  OS: Windows 10 or Windows 11 (**x64 only**; 32-bit environments are not supported)
- ディスク空き容量: 目安2GB以上（インストーラ本体が約700MB、展開後のradioconda環境を含む）  
  Free disk space: about 2 GB or more (the installer itself is about 700 MB, plus the extracted radioconda environment)
- ネットワーク: ADALM-Pluto（Pluto+、DATVファームウェア導入済み）とEthernet同一ネットワークで接続できること  
  Network: must be connectable to the ADALM-Pluto (Pluto+ with DATV firmware) on the same Ethernet network
- 管理者権限: 不要（`PrivilegesRequired=lowest`。ユーザー権限のみでインストール可能）  
  Administrator rights: not required (`PrivilegesRequired=lowest`; can be installed with user rights only)

## 3. ダウンロード / Download

1. リポジトリの[Releases](https://github.com/kazushinjo/Shonan_Lite-win/releases)を開く。  
   Open the repository's [Releases](https://github.com/kazushinjo/Shonan_Lite-win/releases).
2. 最新版の Assets から `ShonanLiteSetup.exe` をダウンロードする。  
   Download `ShonanLiteSetup.exe` from the Assets of the latest version.

## 4. インストール手順 / Installation procedure

1. ダウンロードした`ShonanLiteSetup.exe`をダブルクリックして実行する。  
   Double-click the downloaded `ShonanLiteSetup.exe` to run it.
2. **SmartScreenの警告が出た場合**（コード署名をしていないため表示されることがあります）:
   「詳細情報」をクリックし、表示された「実行」ボタンを押して続行する。  
   **If a SmartScreen warning appears** (it may appear because the installer is not code-signed):
   click "More info", then press the "Run anyway" button that appears to continue.
3. 使用する言語（日本語 / English）を選択する。  
   Select the language to use (日本語 / English).
4. 「使用許諾・免責事項」の画面が表示される。内容（無保証・自己責任、免許と法令の順守など）を読み、
   「同意する」を選んで「次へ」を押す（同意しないとインストールは続行できない）。  
   The "License and Disclaimer" page appears. Read it (no warranty, use at your own risk, licensing and compliance with the law, etc.),
   select "I accept the agreement" and press "Next" (the installation cannot continue without accepting).
5. インストール先フォルダを確認する（既定: `%LOCALAPPDATA%\Programs\Shonan_Lite`。変更も可能）。  
   Check the installation folder (default: `%LOCALAPPDATA%\Programs\Shonan_Lite`; it can be changed).
6. 「デスクトップ上にアイコンを作成する」を必要に応じてチェックする。  
   Check "Create a desktop icon" if you want it.
7. 「インストール」を押すと以下が自動的に実行される:  
   Press "Install" and the following is done automatically:
   - Shonan_Lite本体（`ShonanLite.exe`一式）とffmpegをインストール先フォルダへ展開  
     Extracts the Shonan_Lite app (`ShonanLite.exe` and its files) and ffmpeg into the installation folder
   - **radioconda未導入の場合のみ**、`%USERPROFILE%\radioconda`へGNU Radio実行環境をサイレントインストール
     （**数分かかります**。「GNU Radio 実行環境(radioconda)をインストールしています...」という
     ステータス表示のまま進捗バーが動かないように見えることがありますが、正常です。閉じずに待ってください）  
     **Only if radioconda is not yet installed**, silently installs the GNU Radio runtime into
     `%USERPROFILE%\radioconda` (**it takes a few minutes**. The status may stay at "Installing the GNU Radio
     runtime (radioconda)..." and the progress bar may seem not to move; this is normal. Do not close it; wait.)
   - 事前ビルド済みgr-dvbs2rxをradioconda環境内へコピー
     （既にradioconda導入済みの環境の場合は、radioconda自体の再インストールはスキップされ、
     gr-dvbs2rxのコピーのみ行われます）  
     Copies the prebuilt gr-dvbs2rx into the radioconda environment (if radioconda is already installed,
     reinstalling radioconda itself is skipped and only gr-dvbs2rx is copied)
7. インストール完了画面で「Shonan_Lite for Windowsを実行する」にチェックが入ったまま「完了」を押すと、
   そのままアプリが起動する。  
   On the completion screen, press "Finish" with "Launch Shonan_Lite for Windows" checked to start the app right away.

## 5. インストールされる内容と場所 / What is installed and where

| 項目 / Item | 場所 / Location |
| --- | --- |
| Shonan_Lite本体・ffmpeg / Shonan_Lite app and ffmpeg | `<インストール先>\`（既定: `%LOCALAPPDATA%\Programs\Shonan_Lite\`）とその下の`ffmpeg\`<br>`<install folder>\` (default: `%LOCALAPPDATA%\Programs\Shonan_Lite\`) and `ffmpeg\` below it |
| スタートメニュー / Start menu | 「Shonan_Lite for Windows」グループに登録<br>Registered in the "Shonan_Lite for Windows" group |
| デスクトップアイコン / Desktop icon | インストール時にチェックした場合のみ作成<br>Created only if checked during installation |
| radioconda（GNU Radio実行環境 / GNU Radio runtime） | `%USERPROFILE%\radioconda\`（例 / e.g. `C:\Users\<ユーザー名 / user name>\radioconda\`） |
| gr-dvbs2rx | 上記radioconda環境内の`Lib\site-packages\gnuradio\dvbs2rx\`と`Library\bin\gnuradio-dvbs2rx.dll`<br>`Lib\site-packages\gnuradio\dvbs2rx\` and `Library\bin\gnuradio-dvbs2rx.dll` in the radioconda environment above |

radioconda はShonan_Lite専用ではなく、システム上に1つだけ存在する共有のGNU Radio実行環境という
位置づけです。既に別の用途でradioconda（`%USERPROFILE%\radioconda\python.exe`が存在する状態）を
導入済みの場合、インストーラはradioconda自体の再インストールを行わず、gr-dvbs2rxの追加コピーのみ
行います。

radioconda is not exclusive to Shonan_Lite; it is a shared GNU Radio runtime of which only one exists on the
system. If radioconda is already installed for another purpose (`%USERPROFILE%\radioconda\python.exe`
exists), the installer does not reinstall radioconda itself and only copies gr-dvbs2rx additionally.

## 6. 初回起動と初期設定 / First launch and initial settings

初回起動後、以下を確認・入力する。

After the first launch, check and enter the following.

- **表示言語 / Display language**: ホーム画面から「設定」を開き、「表示言語」で日本語 / Englishを選択する。
  すぐに全画面へ反映される。  
  Open "Config" from the Home screen and choose 日本語 / English under "Display Language". It is applied to every
  screen immediately.
- **送信先（Pluto URI） / Destination (Pluto URI)**: 「出力設定」画面でPluto+のIPアドレスを入力する
  （「自動検出」ボタンでも探せる。Pluto+は事前にEthernetでこのPCと同一ネットワークに接続し、電源を投入しておく）。  
  Enter the Pluto+ IP address on the "Stream Output" screen (the "Detect" button can also find it. Connect the
  Pluto+ to the same network as this PC via Ethernet and power it up beforehand).
- **周波数・バンド / Frequency and band**: 「周波数」画面で運用周波数を入力するか、「バンド選択」で使用する周波数帯を選ぶ
  （1200MHz帯・2400MHz帯・5600MHz帯・10GHz帯・24GHz帯）。  
  On the "Frequency" screen, enter the operating frequency or choose the band under "Band Selection"
  (1200 MHz, 2400 MHz, 5600 MHz, 10 GHz or 24 GHz).
- **PA_Power/PTTコントローラ（ESP32）（任意） / PA_Power/PTT controller (ESP32) (optional)**:
  「設定」画面で、PA_Power/PTTコントローラ(ESP32+W5500)を使用する場合のみIPアドレスを入力する。
  使わない場合は空欄のままでよい。  
  On the "Config" screen, enter the IP address only if you use the PA_Power/PTT controller (ESP32 + W5500).
  Leave it empty if you do not use it.
- **オンデバイス復調 / On-device demodulation**: 送信と受信を同時に実行したい場合は「設定」画面でONにする
  （外部アッテネータ必須。OFFの場合は排他制御され、同時実行できない。アプリ起動のたびにOFFへ戻る）。  
  To run TX and RX at the same time, turn it ON on the "Config" screen (an external attenuator is mandatory;
  when OFF they are exclusive and cannot run at the same time; it returns to OFF at every app start).

映像ソース画面でUSBカメラ/キャプチャデバイスが表示されない場合は、ffmpegが正しく同梱されて
いるか（通常は自動）、カメラのドライバ・接続を確認する。

If the USB camera/capture device is not listed on the Video Source screen, check that ffmpeg is bundled correctly
(normally automatic) and check the camera driver and connection.

## 7. 動作確認 / Verifying operation

- **受信復調が使えるか確認する / Check that reception demodulation works**: 受信画面を開き、「受信開始」を押してエラーダイアログが出ないこと
  を確認する（GNU Radio/radioconda関連のエラーが出る場合は、下記トラブルシューティングを参照）。  
  Open the RX screen and press "Start RX" to confirm that no error dialog appears (if a GNU Radio/radioconda-related
  error appears, see Troubleshooting below).
- **RFループバック確認（推奨） / RF loopback check (recommended)**: TXとRXを直結せず、TX → 40 dB以上の外部アッテネータ → RXの順に
  接続し、送信・受信の双方が正常に動作することを確認する。  
  Do not connect TX directly to RX; connect TX -> external attenuator of 40 dB or more -> RX, and confirm that both
  transmission and reception work correctly.

## 8. アップデート方法 / Updating

新しいバージョンの`ShonanLiteSetup.exe`を[Releases](https://github.com/kazushinjo/Shonan_Lite-win/releases)
からダウンロードし、そのまま実行する。同じインストール先へ上書きインストールされる
（AppIdが固定のため、「別アプリ」としてではなく既存インストールの更新として扱われる）。
既にradioconda導入済みであれば、radioconda自体の再インストールはスキップされる。

Download the newer `ShonanLiteSetup.exe` from [Releases](https://github.com/kazushinjo/Shonan_Lite-win/releases)
and run it as is. It is installed over the same installation folder (because the AppId is fixed, it is treated as an
update of the existing installation, not as a "different app"). If radioconda is already installed, reinstalling
radioconda itself is skipped.

## 9. アンインストール / Uninstalling

1. Windowsの「設定」→「アプリ」→「インストールされているアプリ」を開く。  
   Open Windows "Settings" -> "Apps" -> "Installed apps".
2. 「Shonan_Lite for Windows」を選び、「アンインストール」を実行する。  
   Select "Shonan_Lite for Windows" and run "Uninstall".

radioconda（GNU Radio実行環境）は別アプリとして導入されているため、上記の手順では削除されません。
不要になった場合は、同じく「設定」→「アプリ」から「radioconda」を個別にアンインストールしてください
（他の用途でradiocondaを使っていない場合のみ）。

radioconda (the GNU Radio runtime) is installed as a separate app, so the steps above do not remove it. If it is no
longer needed, uninstall "radioconda" separately from "Settings" -> "Apps" (only if you are not using radioconda for
another purpose).

## 10. トラブルシューティング / Troubleshooting

| 症状 / Symptom | 対処 / Remedy |
| --- | --- |
| SmartScreenで実行がブロックされる<br>SmartScreen blocks the run | 「詳細情報」→「実行」で続行する（コード署名なしの配布物のため表示される、既知の挙動）<br>Continue with "More info" -> "Run anyway" (known behavior for a distribution without code signing) |
| ウイルス対策ソフトが誤検知する<br>Antivirus software raises a false positive | PyInstallerで固めた未署名exeは誤検知されることがある。配布元（本リポジトリのRelease）から入手したものであることを確認のうえ、必要に応じて除外設定を行う<br>An unsigned exe frozen with PyInstaller may be falsely detected. After confirming that it came from the distribution source (this repository's Release), add an exclusion if necessary |
| radiocondaのインストールが数分経っても終わらない<br>The radioconda installation does not finish after several minutes | 600MB近い環境の展開のため数分かかるのが正常。ディスク空き容量とネットワーク（初回展開のみ）を確認し、それでも極端に長い場合のみ再実行する<br>Extracting an environment of nearly 600 MB takes several minutes, which is normal. Check the free disk space and the network (first extraction only), and rerun only if it is still extremely long |
| 受信画面で「GNU Radio」関連のエラーが出る<br>A "GNU Radio"-related error appears on the RX screen | `%USERPROFILE%\radioconda\python.exe`が存在するか確認する。存在しない場合はインストーラを再実行するか、[`docs/gr-dvbs2rx-windows/README.md`](gr-dvbs2rx-windows/README.md)の手順で手動導入する<br>Check that `%USERPROFILE%\radioconda\python.exe` exists. If not, rerun the installer or install manually following [`docs/gr-dvbs2rx-windows/README.md`](gr-dvbs2rx-windows/README.md) |
| 映像ソースにカメラが出てこない<br>The camera does not appear in Video Source | `<インストール先>\ffmpeg\ffmpeg.exe`が存在するか確認する。カメラのドライバ・接続、他アプリでの占有も確認する<br>Check that `<install folder>\ffmpeg\ffmpeg.exe` exists. Also check the camera driver, the connection, and whether another app is using it |
| Plutoが見つからない<br>The Pluto is not found | 出力設定画面の「自動検出」で見つからない場合は、Plutoの電源・LAN接続を確認し、同一ネットワークであることを確認してIPアドレスを手入力する<br>If "Detect" on the Stream Output screen does not find it, check the Pluto's power and LAN connection, confirm that it is on the same network, and enter the IP address manually |
| インストール先を変更したら動かなくなった<br>It stopped working after changing the installation folder | インストール先自体は変更可能だが、`%USERPROFILE%\radioconda`は常に固定パスのため、インストール先フォルダの変更とは無関係に動作する。それでも問題が起きる場合はいったんアンインストールし、既定のインストール先で再インストールする<br>The installation folder itself can be changed, but `%USERPROFILE%\radioconda` is always a fixed path and works independently of the installation folder. If a problem still occurs, uninstall and reinstall to the default folder |
